# Request: Wow! Signal follow-up observing metadata and completeness

**Subject:** Request for follow-up observation metadata to model selection effects reproducibly

We are preparing a methods-focused, non-attribution analysis of the Wow! Signal. We require campaign-level information to avoid treating heterogeneous follow-up as a single exposure duration.

For the relevant campaign, please identify or provide, if available:

1. start/end UTC windows for each pointing or scan;
2. pointing coordinates, beam model, and sky coverage;
3. frequency coverage, channel resolution, integration time, and drift-rate treatment;
4. flux-density calibration and detection threshold/completeness versus flux, position, linewidth, and drift;
5. candidate-selection pipeline and known exclusions/quality flags;
6. stable citation, archive identifier, or data-use restrictions.

If only aggregate exposure is available, we will record that limitation and will not convert it into a complete transient non-detection likelihood.
