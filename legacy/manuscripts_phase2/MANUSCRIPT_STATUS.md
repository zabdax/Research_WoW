# Manuscript Status

**Date:** 2026-08-20

The manuscripts in this directory (`legacy/manuscripts_phase2/`) are **SUPERSEDED** and preserved for historical provenance only. 

These documents were drafted around the legacy Phase 2 prototype's outputs (e.g., claiming a five-way posterior where H3 = 75.3%, H5 = 16.5%, H4 = 8.2%). The underlying methodology for those numbers involved heuristic, hand-elicited component probabilities and a shared rarity scalar applied incorrectly across hypotheses without a demonstrated conditional-independence model. 

The project has transitioned to a strict generative Bayesian framework. Because critical physical/population priors (e.g., empirical HI cloud counts, authoritative ephemerides, Big Ear beam calibrations) are currently missing, the revised pipeline correctly blocks the emission of any five-way confirmatory posterior.

**Do not quote values from these legacy manuscripts.** All new scientific writing will originate from the revised framework, emphasizing validated feasibility bounds and exact emulator reproductions rather than heuristic posteriors.
