## 2. Key correction to the prior forensic record

The earlier pass reported "all text is vectorized outlines; 28/37 streams
decompress with zero readable text — OCR required". That conclusion is
**superseded**: PyMuPDF's text-layer extraction returns 4,740–5,597
readable characters per page with clean wording. The likely cause of the
earlier failure was tooling (stream-level decompression rather than
font/ToUnicode-aware extraction). The PDF fonts carry usable character maps
except for a small set of math glyphs.
