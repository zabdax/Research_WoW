   J2000 19:23:03 −26:43:24 (±1° Dec off-pairs), which is neither beam locale.
   Do you recall why that position was chosen (or is it defined in Michael's
   materials)?
3. **Search outcomes.** Did any search/analysis of the 2010–2014 data actually
