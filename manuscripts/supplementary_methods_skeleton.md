# Supplementary Methods Skeleton

## S1. Provenance and evidence classification
For each input, report source class, publication status, locator, extraction status, units, uncertainty/censoring, and downstream model term.

## S2. Observation model and dependency graph
State the joint likelihood and all conditional-independence approximations. Show how frequency, flux, duration, beam response, localization, rate, and follow-up detection are conditioned.

## S3. Big Ear geometry calibration
Document beam-map/receiver source material, coordinate frame, horn separation, response parameterization, and calibration validation. Mark exploratory configurations as non-confirmatory.

## S4. Follow-up selection functions
Give per-campaign coverage, threshold/completeness model, cadence, field response, line-width/drift dependence, and no-detection likelihood.

## S5. Hypothesis models
Separate physical feasibility, population/event-rate priors, observation likelihood, and follow-up likelihood for H1--H5.

## S6. Replication and computation
Document upstream asset hashes, code version, configurations, seeds, grid settings, Monte Carlo uncertainty/convergence, and generated artifact hashes.

## S7. Robustness and posterior prediction
Report prior families, likelihood uncertainty, model prior-volume tests, posterior predictive checks, and held-out benchmark protocol.
